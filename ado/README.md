# ADO — GE daily work tracker

Purpose: Track ADO stories/tasks for GE work (FSR prod + OSA) and keep a short daily standup script ready for the 6 AM standup.

## Files

- `stories.md` — running list of ADO stories/tasks I own, with parent umbrella IDs once known.
- `standup.md` — short paragraph for tomorrow's standup. Update at end of each day.

## Workflow

1. End of day → update `standup.md` with: *yesterday / today / blockers*.
2. New work that needs an ADO task → add to `stories.md`, ask for umbrella story if needed.
3. Open this folder at 5:55 AM, read `standup.md` aloud at 6 AM.

## Scope

GE only — FSR prod-ops + OSA discovery. Personal tasks, learning, certs stay in the parent `ai-arch/` tracker.
