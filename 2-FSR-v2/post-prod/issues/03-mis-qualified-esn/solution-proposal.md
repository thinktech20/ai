# Solution Proposal

Updated: 2026-09-15
Issue: Mis-qualified ESN retrieval

## Proposed direction

Review whether region-level ESN evidence should take precedence over broad active-ESN qualification for retrieval eligibility.

## Proposed actions

- Compare current retrieval results using active ESN qualification versus region-level ESN qualification.
- Narrow qualification rules if the broad active-ESN path is confirmed to be the cause.
- Recheck shared versus non-shared behavior before rollout.

## Expected outcome

The wrong document-to-ESN association should stop surfacing without reducing valid retrieval coverage for correctly qualified documents.
