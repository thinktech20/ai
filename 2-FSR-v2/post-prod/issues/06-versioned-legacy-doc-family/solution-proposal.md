# Solution Proposal

Updated: 2026-09-15
Issue: Versioned and legacy doc family

## Proposed direction

Treat legacy and versioned documents as an explicit family with dedicated validation coverage and profile rules.

## Proposed actions

- Validate structural similarities across the two groups.
- Design a family-specific processing profile.
- Include ESN typo cases in the validation set.

## Expected outcome

The family should be handled more predictably without distorting the default UUID path.
