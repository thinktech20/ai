# Helpers Workspace

Use this folder for temporary and evolving helper utilities used during RCA and validation.

Current convention:
- Keep ad-hoc scripts, quick analyzers, and export/import helpers here.
- Keep generated outputs under `../analysis-output/`.
- Keep notebook-facing run instructions under `../analysis-output/` or this folder.

Notes:
- This folder is intentionally lightweight for active investigation.
- We can reorganize and split into stable utilities later.
