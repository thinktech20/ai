# REChainExperiment

Active extracted REChain runtime used for the March 2026 self-managed embedding migration.

This folder is the working code path for the current evaluation runs. ER and FSR retrieval now use self-managed Databricks Vector Search indexes, with query embeddings generated through the LiteLLM Azure embedding gateway.

## Current Flow

1. Heatmap lookup from `fsr_unit_risk_matrix_view.xlsx`
2. ER retrieval from `main.gp_services_sdg_poc.vs_engineering_report_chunk_litellm`
3. IBAT lookup from Databricks SQL
4. FSR retrieval from `main.gp_services_sdg_poc.vs_field_service_report_gt_litellm`
5. LLM risk assessment through LiteLLM

Both ER and FSR query the Vector Search REST API with `query_text` and an explicit `query_vector` generated by `vector_embeddings.py`.

## Configuration

The runtime no longer stores credentials in source.

`config.py` now loads configuration in this order:

1. Existing environment variables
2. `.env` in this extract folder
3. `.env` in the parent workspace
4. Optional local secret files: `dbr_token.txt`, `litellm_token.txt`

Use `.env.example` as the starting point for local setup.

Important variables:

| Variable | Purpose |
|---|---|
| `DATABRICKS_HOST` | Databricks workspace URL for Vector Search |
| `DATABRICKS_SERVER_HOSTNAME` | Databricks SQL hostname |
| `DATABRICKS_SQL_HTTP_PATH` | Databricks SQL warehouse path |
| `DATABRICKS_TOKEN` | Databricks token used for SQL and Vector Search |
| `LITELLM_BASE_URL` | LiteLLM gateway base URL |
| `LITELLM_API_KEY` | LiteLLM gateway token |
| `VS_INDEX_NAME` | FSR self-managed index |
| `ER_VS_INDEX_NAME` | ER self-managed index |
| `RE_CHAIN_OUTPUT_SUBDIR` | Output subfolder under `REChainExperiment/` |
| `RE_CHAIN_MAX_WORKERS` | Outer batch worker count |

## Running

From `_tmp/REChain_new_extracted_20260318`:

```bash
python run_pipeline.py
```

That runs the general launcher and expands `ALL` issues/components from the heatmap.

For the active 26-ESN run:

```bash
python run_pipeline_26_esns.py
```

That launcher:

- targets the 26 ESNs present in the FSR GT subset
- sets `config.max_workers = 5`
- writes to `REChainExperiment/output/10unitSL-chunk20-run1-ervs/26esn_selfmanaged_litellm_20260318/`

## Outputs

Each batch run writes into the configured output directory:

- `re_chain_results.csv`
- `re_chain_condensed.csv`
- `ground_truth_diff.csv`

The batch runner resumes from an existing `re_chain_results.csv` unless `RE_CHAIN_FORCE_RERUN=true` is set.
