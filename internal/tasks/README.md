# Task Intake

Use this folder for urgent or short-lived requests that should not create new date-based folders.

## How to use it

1. Create one markdown file per request.
2. Name it by topic, not by date.
3. Capture context, question, findings, decisions needed, and next action.
4. When the task is done, merge durable content into the canonical docs in `internal/` or `internal/summaries/`.
5. Then delete the task note if it is fully absorbed.

## Suggested template

```md
# Task Name

## Context

## Question or request

## Findings

## Decisions needed

## Next action
```
